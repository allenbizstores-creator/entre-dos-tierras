# Entre dos tierras

Presentación documental de 15 beats sobre identidad y migración entre República Dominicana y Nueva York.

## Abrir localmente

No necesita instalación ni proceso de compilación. Abra `index.html` directamente en un navegador moderno, o use cualquier servidor estático.

## Edición rápida

- Texto, notas y fuentes: `content.js`
- Diseño, transiciones y mapa SVG: `styles.css` y `app.js`
- Estructura base: `index.html`
- Fotografías locales: `assets/photos/`
- Licencias y atribución: `image-manifest.json`

La escena de “Las horas santas” usa una imagen neutral claramente identificada hasta que exista una fotografía personal o se confirmen más detalles.

## Controles

- Flechas izquierda/derecha: avanzar o retroceder un beat
- Espacio o Enter: avanzar
- `N`: abrir las notas del presentador
- `F`: alternar pantalla completa
- Escape: cerrar notas/fuentes o salir de pantalla completa
